# Contributing

Please include a concise description, reproduction command, package versions and a small regression test. Do not include dataset dumps, credentials, local paths or model binaries in Git commits. Preserve label IDs, checkpoint/config identity and evaluation/timing boundaries when comparing results. Run `python -m unittest discover -s tests` and `python -m tools.verify_assets` before proposing changes. Original release-tool contributions use MIT; retain all third-party notices.
